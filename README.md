# BReasy!

A portable desktop utility for Windows 10 and Windows 11 (64-bit).

## Features

- Screen and window recording with pause and resume.
- System or application audio and microphone recording.
- Optional separate audio tracks.
- Audio mixer, gain, compressor, limiter, and expander.
- Push-to-talk microphone control.
- Screenshots with annotation tools.
- Reminders with scheduling options.
- Window pinning, calculator, timer, and stopwatch.
- Customizable hotkeys and support for 13 interface languages.
- Built-in offline user guide.

## Download

Available builds can be found on the [Releases page](https://github.com/FySyde/BReasy/releases).

## Getting started

1. Download the portable ZIP archive from Releases.
2. Extract the entire archive to a writable folder.
3. Run `BReasy.exe` and approve the Windows administrator prompt.
4. Open the system tray menu to access the tools.

No separate Python installation is required.

## Updating

Exit BReasy through its system tray menu before updating. Back up your `program/settings.json` file and personal recordings, screenshots, and tutorial media.

## Development status

BReasy is under active development. Recording performance depends on your hardware, drivers, and selected settings.
